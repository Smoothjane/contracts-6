# Code of Conduct

StellarPOS follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be respectful. Critique code and ideas, never people.
- Assume good intent, and ask before assuming.
- Help newcomers; everyone started somewhere.
- No harassment, discrimination, or personal attacks, in any project space:
  issues, pull requests, discussions, and chat.

## Reporting

Report unacceptable behavior privately to the maintainers by opening a
[private security advisory](../../security/advisories/new) marked "Conduct", or
by contacting a member of the `StellarPOS-App` organization directly. Reports
are handled confidentially.

## Enforcement

Maintainers may remove, edit, or reject comments, commits, code, issues, and
other contributions that do not follow this code, and may temporarily or
permanently ban contributors for repeated or severe violations, following the
Contributor Covenant enforcement guidelines.
